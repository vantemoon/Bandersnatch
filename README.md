# Bandersnatch 

An interactive visual novel built in Unity, featuring branching choices and player-driven storytelling. 

## About 

**Bandersnatch** is a Unity-based interactive visual novel where players progress through a narrative by making choices that shape the story path. The project focuses on dialogue flow, decision-making, and branching narrative structure. 

## Features 

- Interactive visual novel gameplay
- Branching dialogue and story choices
- Unity-based scene and UI implementation
- Player-driven narrative progression
- Simple and readable project structure

## Built With

- Unity
- C#
